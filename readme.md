# Data Analysis Course

A comprehensive Python data analysis course covering foundational to intermediate concepts in data manipulation, cleaning, visualization, and statistical analysis using popular libraries like pandas, numpy, and matplotlib.

## 📊 Course Overview

This repository contains all materials for a two-day intensive data analysis workshop designed to equip students with practical skills in data science using Python. The course progresses from basic data structures to advanced data cleaning and visualization techniques.

## 🗂️ Course Structure

### Day 1: Fundamentals of Data Analysis
- **1-Series**: Introduction to pandas Series objects
- **2-DataFrame**: Working with pandas DataFrames
- **3-Read Data**: Techniques for importing data from various sources (CSV, Excel, JSON)
- **4-Write Data**: Exporting data to different file formats
- **5-Elementary Operation**: Basic data manipulation operations
- **6-Basic Statistics**: Statistical analysis with pandas and numpy
- **datasets**: Sample datasets for practice

### Day 2: Data Cleaning and Visualization
- **1-Handling_Missing_Values**: Strategies for dealing with null values
- **2-Duplicates_detect**: Finding and removing duplicate records
- **3-Encoding_Categorical_Values**: Converting categorical data to numerical formats
- **4-Numerical_Fields_Handling**: Working with numeric data types
- **5-Group BY**: Aggregation techniques using groupby operations
- **6-Concatenate and Merg and Append**: Combining datasets
- **7-Plotting**: Data visualization with matplotlib and seaborn
- **8-Animated Bar Chart**: Creating dynamic visualizations
- **Datasets**: Additional datasets for Day 2 exercises

### Extra Demos
- Additional examples and advanced topics for further learning
